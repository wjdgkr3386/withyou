# 📘 withyou

**withyou 프로젝트**는  
온라인 환경에서 **수학 문제 학습 · 시험 · 성적 관리**를 통합적으로 제공하는  
학원 전용 웹 서비스입니다.

오프라인 학원의 운영 방식을 온라인으로 확장하는 것을 목표로 하며,  
학생·강사·관리자 역할에 맞춘 기능을 제공합니다.

---

## 🧩 주요 기능

### 1️⃣ 문제은행 기능
- 단원별 / 난이도별 문제 관리
- 객관식 · 주관식 문제 지원
- 문제 등록, 수정, 삭제 (강사/관리자)
- 문제 랜덤 출제 기능

---

### 2️⃣ 온라인 시험 기능
- 시험 생성 및 일정 관리
- 시험 시간 제한
- 문제 자동 출제
- 시험 응시 및 제출
- 객관식 자동 채점

---

### 3️⃣ 성적 관리 기능
- 시험별 성적 조회
- 학생 개인 성적 히스토리
- 평균 점수 및 통계 제공
- 강사용 학생 성적 관리

---

## 🛠 기술 스택

### Frontend
- **Next.js**
  - React 기반 프레임워크
  - SSR을 활용한 SEO 대응
  - 학원 소개 페이지 검색 노출 최적화

### Backend
- **Spring Boot**
  - REST API 서버
  - Spring MVC 기반 구조
  - 인증 및 권한 관리

### Language
- **Java**

### Database
- **MySQL**
  - 문제, 시험, 성적 데이터 관리
